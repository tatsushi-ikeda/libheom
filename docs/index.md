# LibHEOM

`libheom` is a C++17/CUDA library for open quantum dynamics simulations using the
hierarchical equations of motion (HEOM) theory and the Redfield master equation.

Based on: Ikeda & Scholes, *J. Chem. Phys.* **152**, 204101 (2020), https://doi.org/10.1063/5.0007327 (arXiv: https://arxiv.org/abs/2003.06134).
